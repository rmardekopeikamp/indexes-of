# jankenpo-laravel


> [!TIP]
> A ordem dos passos importa: nao pule a preparacao do ambiente.

Jogo de pedra, papel e tesoura montado com o framework PHP mais usado.

Uma rota recebe a jogada, um controlador compara com a escolha do computador e uma view devolve o resultado. Não há banco de dados: o placar vive na sessão.

Há uma gravação mostrando a partida completa.
